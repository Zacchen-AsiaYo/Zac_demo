## 製作原則

- **文案逐字沿用**線上頁面（行程簡介、遊輪簡介、艙等/艙房說明、費用說明、注意事項、退訂政策、訂購流程、常見問題 FAQ、SEO FAQ、Footer 皆完整保留，未刪節）。
- **圖片沿用**原站 CDN（`image-store.asiayo.com`、`gsimg.asiayo.com`、`img.asiayo.com`），未下載到本機 → 需連網才會顯示。
- **不複製互動**：僅保留三個純視覺互動 —— 出發日 pill 切換、艙等分組展開／收合、艙等/房型 chip 切換。沒有真實庫存、價格計算、訂購流程。
- 版型量測自線上頁面：容器 1280 / 內容欄 840 + 側欄 352、gap 24；主色 `#1e9fd2`；標題 32/44、H2 24；`選擇方案` 區塊底色 `#fafafa`。

## 2026-08-19 更新：套用《郵輪標籤書寫規範》

兩頁商品內容已依規範 artifact（2026-08-19 版）重新標記與格式化；**規範 1.4.1／1.4.2／1.5 未套用**。
未標記的原始復刻版備份於 `_original/`。

### 標籤視覺呈現

| 顏色 | 意義 | 例 |
| :--- | :--- | :--- |
| 藍綠 | DNT XML 標籤（不翻譯值） | `<cruiseCabinCategory>內艙 ( Interior )</cruiseCabinCategory>` |
| 棕金 | 可翻譯 XML 結構化標籤 | `<cruiseRoute>…</cruiseRoute>`、`<eligibilityRestriction>…</eligibilityRestriction>` |
| 紫 | translate 詞庫標籤 | `<translate={id}>艙等</translate>` |

開閉標籤由 CSS 自動生成（`.xml` + `data-tag`），id 一律以 `{id}` 占位。

### 套用的規則

1. **11 段固定結構與標題**（標題包 translate）：概述 → 選擇出發日 → 行程簡介 → 郵輪簡介 → 艙等說明 → 交通接駁 → 費用說明 → 注意事項 → 退訂政策 → 訂購流程 → 常見問題。改字：遊輪簡介→郵輪簡介、艙房介紹→艙等說明、選擇方案→選擇出發日、常見問題 FAQ→常見問題、載客量→載客數、人數→可容納人數、房間大小→坪數、設備→設施。缺內容的段落整段省略（home 無交通接駁）。
2. **XML 值標記**：艙等（代號 - 名稱 ( 英文 )）、航線行（cruiseRoute，內部地名巢狀 translate）、逐港時刻、品牌/船名（讀者語系 ( 英文 )）、客服電話（+國碼-區碼-號碼，分機在標籤外）、參加資格逐條。
3. **屬性文字（Zac 裁定）**：只有與 XML 標籤**有子母關係**的 label 包 translate（艙等、客服電話…）；無子標籤的規格詞維持純文字。
4. **排版**：■ → •（系統列點）→ ★ 三層條列；欄位式「名稱：內容」；補充用 ※ 換行；缺資料整行不寫；多值行首「- 」；內容不放 Emoji。
5. **訂購流程去圖字化**：兩頁的流程圖（文字壓圖）均轉錄為純文字步驟（fly = NCL 3 步版、home = MSC 4 步版）。
6. **內容歸位**：home 每日「價格包含所有費用和稅金」→ 費用說明；fly 的 NCL Ground Transfers（FAQ）→ 新增「交通接駁」段；原位皆留 ※ 導引句。
7. **金額規定值**：退訂政策定額（TWD 5,000／6,000／8,000／30,000、3,600 TWD）包 translate；百分比不包。

## 2026-08-20 更新：套用書寫規範 v1.1（現行版）

兩頁（含 `_plain`）已依 `cruise_書寫規範.md` v1.1 與兩張使用規範表（2026-08-20 修訂）更新，**以下取代上方 8/19 條目中衝突的規則**：

1. **時間屬性詞改名**：抵達時間 →「停靠/抵達時間」、啟航時間 →「啟航/出發時間」；格式 `屬性詞：【 港名 】YYYY-MM-DD(DDD) , HH:MM ～ HH:MM`——**【 】內只放港名、不再寫「抵達／啟航」字樣**，停靠時段直接銜接，日期或時刻缺一可省略（fly 頁時刻未綁定航次日期，故只寫時段）。
2. **「停靠日期」屬性詞移除**：逐日順序由航線的 Day N 承載。
3. **航線(停靠港)改條列式逐日**：`- Day {N} : 地點 ( 英文 )`，每行各包一個 cruiseRoute，行內港名主體另包 translate。
4. **郵輪名稱改格式**：`【 讀者語系 ( 英文 ) 】航程`（【 】與航程在標籤外）。
5. **艙等**：每筆各自帶屬性詞「艙等：」；固定子項目 可容納人數／坪數／樓層（缺項跳過）；描述文字不可刪、改 ※ 列點；複數代號「/」串接（IF/IC/IB/IA）。
6. **單語主體**：中英兩份並排的段落只留繁中主體＋括號英文。
7. **選擇出發日全區去英文**（Zac 2026-08-20 裁定）：分組標頭與艙等/房型選項按鈕不帶 ( 英文 ) 對照。
8. 「※ 原頁面標示：<12 小時制時刻>」重複保留行已移除（資訊已在停靠/抵達時間欄位）。
9. **編輯過程註記收進備註元件**（Zac 2026-08-20 裁定）：說明「原文是如何」（※ 原頁面標示…）或「原文被移動到哪裡」（※ …已移至某段落）的編輯過程註記，不得直接鋪在畫面上，一律改為原生 `<details class="edit-note"><summary>註</summary><div>…</div></details>` 元件（inline 擺在原位置，點擊「註」徽章展開；樣式在 `assets/style.css` 末端）。規範要求的**商品內容補充**（免責句、16:00 登船、艙等描述 ※、年齡計算 ※ 等）不適用本元件、維持鋪在畫面；四檔（含 `_plain`）皆套用此慣例。

> `score_report.md` 為 **8/19 舊版的歷史評分報告**，其引用的頁面片段（如【 港名 抵達 】格式）為當時舊規則，非現行頁面內容。
